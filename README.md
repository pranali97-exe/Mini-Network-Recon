# Mini Network Recon 🔎

A beginner-friendly cybersecurity project using Python and Nmap for basic network reconnaissance and service detection.

## 📌 Project Objective

The objective of this project is to understand the basics of network reconnaissance, port scanning, and service detection using Python and Nmap.

## 🛠️ Technologies Used

- Python 3
- Nmap
- Kali Linux

## 🚀 Features

- Takes an IP address or hostname as input
- Performs a basic Nmap scan
- Detects open ports
- Identifies running services and their versions
- Displays scan results in the terminal

1. Make sure Nmap is installed:

2. Run the python script:
